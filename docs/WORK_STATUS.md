## Lịch sử runtime Windows trước khi chuyển Docker

- Backend được khởi động lại trên `127.0.0.1:8000`; `/health` trả `ok`. Đọc DB ở chế độ read-only trước khi khởi động thấy 1 job failed, không có queued/processing. Không retry video cũ, không xoá input/attempt.
- Chẩn đoán lúc đó thấy bốn công cụ OpenMVS bị Windows Code Integrity chặn `OpenEXR-3_3.dll` (event 3033/3077, exit `0xc0e90002`). Blender vẫn chạy. Bản Windows còn bị chặn; bản Linux Docker hiện đã startup được, không sửa policy Windows.
- Lúc đó Docker Desktop đã cài nhưng daemon chưa chạy và chủ máy chưa chọn runtime. Chủ máy sau đó đã cho phép cấu hình Docker; trạng thái mới ở đầu tài liệu thay thế trạng thái chờ quyết định này. Bằng chứng Code Integrity vẫn được giữ trong run Windows cũ.
- Doctor và runner bổ sung báo lỗi/exit code đúng; `-RequireNative` yêu cầu startup/DLL check thật. Xem [NATIVE_RUNTIME.md](NATIVE_RUNTIME.md) và [thu thập lại vật thật](REAL_SCAN_ACCEPTANCE.md).
